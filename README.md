## 📌 Overview

This repository hosts the personal portfolio website of **Sunil Dennis**, Full Stack Software Engineer and MSc IT Project Management student at Sheffield Hallam University. The site is optimized for performance, accessibility, responsive design across mobile and desktop, and zero dependencies.

### Features
- **Modern Dark/Light UI**: Built with CSS custom properties, glassmorphism blur effects, and smooth transitions.
- **Interactive Project Filtering**: Dynamically filter projects by category (Backend & APIs, Full Stack, DevOps & Cloud).
- **CV Download**: Direct link to the latest curriculum vitae.
- **Direct Contact & Clipboard Integration**: Quick mailto actions and one-click copy email feedback.
- **Zero-Build Deploy**: Directly served by GitHub Pages without complex build chains.

## 🚀 Local Development

To run or preview locally:

```bash
# Clone the repository
git clone https://github.com/sunildennisb7/sunildennisb7.github.io.git

# Navigate into the folder
cd sunildennisb7.github.io

# Serve with any lightweight server (e.g. Python 3)
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
